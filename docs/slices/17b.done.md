# Slice 17b (web): done

Screen A15 `/admin/audit`, the audit log for the owner.

## Built

- `web/src/app/(admin)/admin/audit/page.tsx`: server route. Owner: first page of the log, the
  elections and the team are read on the server. A manager gets the `NotOwner` card
  (`data-testid="turned-away"`, they stay signed in).
- `web/src/components/audit/`: `AuditPage` (filters, export, show more, empty state), `AuditCard`
  (icon by family, action in words or the raw code, actor, election chip, local time with UTC title,
  address when there is one), `NotOwner`, `auditModel` (+ test).
- `web/src/lib/api/audit.ts` (types from the generated schema), `fetchAudit` and
  `downloadAuditExport` in `browser.ts`, `fetchAuditFirstPage` in `server.ts`.
- Messages `audit.*` in fr and en (every action code of the slice file, families, filters,
  export, empty state, not-owner card).
- Side menu: the "Audit log" entry is shown to owners only (also in the "go to" search).
- Export buttons fetch `/audit/export` with the current filters and save the file under the name
  the API gives (so a 429 or 422 is said in words).

## Results

- `make lint-web`: 0 errors (1 existing warning, `ballotTurnout`); `make test-web`: 76 files, 622 tests;
  `make generate-check`: clean.
- `e2e/slice17` desktop 4/4, phone 4/4.

## Deviations and notes

- The dev database lacked the `app` INSERT grant on `audit_entries` (every audited write answered
  500). `docker compose run --rm migrate` (migrations and `db:grant-app`) fixed it; no code change.
- A filter chosen before hydration (slow phone) is read from the field once the page is
  interactive, so it is not lost.
- `e2e/slice03` expects `/admin/audit` to be the "not available yet" placeholder: `language.spec.ts`
  ("is the language of every admin page", the `coming-soon` check) and `shell.spec.ts` ("opens every
  entry inside the shell") now fail. Those specs need updating by Opus; not edited here.
