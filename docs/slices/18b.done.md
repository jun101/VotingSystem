# Slice 18b (web, plus two tooling items): done

Screen A16 `/platform`, the sign-in refusal with its reason, and the paused vote page.

## Built

- **Command**: `platform:create-admin {email} --password-from-env=NAME` reads the password from that variable (no
  question, no confirmation, 12 to 128 characters; unset or empty gives exit 1; never printed).
- **Makefile `e2e`**: creates `e2e-admin@platform.test` after `up -d --wait`, tolerating "already exists".
- **`/platform`** (`web/src/app/(platform)/platform/page.tsx`, `web/src/components/platform/`): `PlatformPage` (hero
  with the language switch and sign-out, live search, status filter, "show more", empty states, suspend dialog with a
  required reason, reactivate dialog, errors in words), `InstitutionCard` (status chip with icon, counts, election
  chips by status, created and last sign-in dates, reason), `platformModel` (+ test). Guard: signed out goes to
  `/login`, an owner or manager to `/admin`. `/admin` sends a platform admin to `/platform`; sign-in sends them there
  directly (also after the two-factor step). The proxy marks `/platform` as an admin-language area.
- **Removed**: `TurnedAway`, `admin.turnedAway.*`, `auth.login.platformAdmin`, the `?platform=1` login notice.
- **Sign-in refusal**: `ApiError.reason` (`error.reason`); the login page (password and two-factor steps) shows
  `login-suspended` with the reason alone in `login-suspended-reason`; the `?suspended=1` notice is unchanged.
- **Vote page**: phase `paused` shows `vote-paused` (heading, text, hint; fr and en); a refused session gives
  `vote.error.election_not_open_paused`. `phaseOf` in `lib/api/vote.ts` accepts `paused`.
- `ConfirmDialog`: textarea added to the focus-wrap selector (the suspend dialog holds one).
- Messages: `platform.*`, `vote.paused.*`, `errors.already_suspended`, `errors.not_suspended`,
  `validation.platform.suspend.reason.*`, `auth.login.suspendedReason`.
