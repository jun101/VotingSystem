# Slice 16 — Publication

Brief · 2026-10-12 · branch `slice/16-publication` (from `slice/15-results` until it is merged) · the decisions below
were proposed by the assistant and **confirmed by Jun on 2026-10-12** (a failing bulletin check blocks publication;
archiving takes a published election off the public pages; the winners-only display shows turnout, winners and tied
candidates, no counts). The other rows are the assistant's defaults, not yet questioned.

## Goal

1. An institution user **publishes** a closed election's results (and unpublishes, archives, unarchives) (FR-RES-04,
   FR-ELEC-03).
2. Anyone, without signing in, opens `/results/{election}` and `/institutions/{institution}` (FR-RES-04, FR-RES-07).
3. The institution chooses whether the public page shows **full counts or only winners and turnout** (FR-RES-08).
4. The public page can be shared with a correct preview and share buttons (FR-RES-05); results are downloadable as a PDF
   report and as a social image (FR-RES-06).

## Requirements covered

FR-RES-04 to FR-RES-08, FR-ELEC-03 (Published, Archived), FR-SEC-03, FR-SEC-04, FR-SEC-09, NFR-SEC-03, NFR-UX-02,
NFR-UX-03, NFR-SEC-08.

## Decisions

| Question | Proposal |
|---|---|
| Who may publish | Owner and manager, like the rest; no typed confirmation (it can be undone) |
| Bulletin check fails | Publication is refused (409 `results_check_failed`); a tie does not block it |
| The display setting | The election's `results_display`; `publish` may set it. Winners-only hides votes, percentages, blank counts and the check |
| After unpublish | Back to `closed`, nothing public at once |
| Archive | From `closed` or `published`; archiving also takes it off the public page; unarchive returns to `closed` |
| Public caching | `Cache-Control: no-cache` on the public API so an unpublish is immediate |
| PDF | TCPDF (already a dependency), US Letter, generated on request (small); the public one follows the display setting |
| Preview image | Generated by the web application at `/results/{election}/opengraph-image` (1200 × 630 PNG: institution, title, winners); the "download image" button is the same file |
| Suspended institution | Its public pages answer 404 |
| Photos | Candidate photos are shown (they are already public to voters) |
