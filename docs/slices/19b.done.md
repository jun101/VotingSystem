# Slice 19b (web and proxy) and review fixes: done

Branch `slice/19-security-hardening`. Follows [19a](19a.done.md).

## Built

- **Web CSP** (`web/src/proxy.ts`, `contentSecurityPolicy`): a nonce per request (`btoa(crypto.randomUUID())`), set on the
  request (Next.js puts it on its own scripts and styles; `x-nonce` for server components) and on the response.
  `script-src 'self' 'nonce-…' 'strict-dynamic'`, no `unsafe-inline` for scripts; `style-src 'self' 'nonce-…'` with
  `style-src-attr 'unsafe-inline'` for React `style` attributes (written into the brief's "Web CSP" row);
  `frame-ancestors`, `base-uri`, `object-src 'none'`, `form-action 'self'`. `unsafe-eval` only when `NODE_ENV` is not
  production and `CSP_DEV_UNSAFE_EVAL=1` (off in Compose).
- **Proxy files**: the proxy no longer adds a Content-Security-Policy (the web app and the API send their own, never
  twice); `Permissions-Policy` in both Caddyfiles; `Referrer-Policy` is set with `?` (only when the answer has none), so the
  API's `no-referrer` survives. The `/media` sandbox policy is unchanged.
- **Platform screen**: a platform admin without two-factor, where the rule is on (production), sees a screen that says
  why and the two-factor card (`TwoFactorRequired`, `platform.twoFactorRequired*` in fr and en, `errors.two_factor_required`).
  `fetchPlatformFirstPage` returns `'two-factor-required'` for that 403.
- **Review fixes (server)**: `vote-audit:read` appends its log line before the CSV exists and exits 1 with no CSV when it
  cannot (outcome `error` when reading fails), reads votes and candidates in chunks of 1 000 (a large election passed the
  65 535 placeholders), accepts the key from a pipe with `--key-stdin`, wipes the key after use (`#[SensitiveParameter]`,
  `sodium_memzero`), creates the log with mode 0600, and refuses when no `audit_reader` account is set (the migrator
  fallback only on `local` and `testing`). `platform.require_two_factor`: a value that is not a boolean never switches the
  rule off in production.
- **Docs**: command file (grant tables, log before CSV, `error` outcome), the public results endpoint file (`Cache-Control`
  is `no-cache, no-store, private`), the brief.
